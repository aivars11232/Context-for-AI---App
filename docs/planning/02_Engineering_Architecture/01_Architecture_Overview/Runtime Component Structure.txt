MVP runtime (canonical):
Context for AI Desktop — one Python/PySide6/QML process
│
├── QML UI and bounded foreground request task
├── application orchestrator and deterministic context engine
├── SQLite embedded database
└── buffered client to one configured local Ollama text-generation model

SQLite is embedded storage, not a process. Interpretation and validation are
rule-based and do not use a model in MVP. Vector stores, embedding models,
separate UI/application-service processes, and multiple model roles are
Deferred Post-MVP.

Deferred Post-MVP:
small fast model
    → interpretation and validation

larger model
    → final response generation

embedding model
    → semantic retrieval
