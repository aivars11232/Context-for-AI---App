MVP status: types include `ASSUMED`; canonical numeric priority bands, conflict
groups, conditional activation, and clarification rules are in
`DomainAndDecisionRules.md`. The `priority: 100` example below is historical,
not an MVP priority value.

Constraint types:
REQUIRED
FORBIDDEN
PRESERVE
PREFERRED
OPTIONAL
CONDITIONAL
ASSUMED

Example:
{
  "type": "FORBIDDEN",
  "rule": "Do not generate an image",
  "priority": 100,
  "scope": "current_response",
  "source": "current_user_message"
}
