Recommended MVP version
Do not build all modules immediately. The canonical MVP contains the chat UI,
state manager, deterministic interpretation/constraints/references/confidence,
explicit manual memory lifecycle plus deterministic retrieval, SQLite, packet
builder, one buffered Ollama connector, deterministic validation/bounded
correction, context inspection, and versioned evaluation tests.

The first functional pipeline would be:
User message
    ↓
Load current project state
    ↓
Extract intent, references and constraints
    ↓
Retrieve relevant memories
    ↓
Build structured context packet
    ↓
Send it to Ollama
    ↓
Validate response
    ↓
Show response
    ↓
Update session state
