User Input Layer:
Receives the user's message and basic metadata.

It should capture:
exact original wording
current conversation
attached files or images
selected project
active AI model
time of the message
whether the user requested an action, explanation, description, code change, image generation, and so on
The original message must never be overwritten. The app should preserve it exactly
