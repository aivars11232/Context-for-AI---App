This tracks what is happening right now.

MVP status: the Arch Dock object below is a historical fixture, not an active
default project. MVP state is limited to the canonical conversation project,
topic, task, previous task, expected output type, topic stack, and version.
Completed/pending steps, file/version, application, accepted/rejected
approaches, and unresolved-question tracking are Deferred Post-MVP unless they
are represented by one of those canonical fields.

Example:
{
  "active_project": "Arch Dock",
  "active_topic": "dock appearance",
  "current_task": "write a Canva description",
  "task_status": "in_progress",
  "previous_task": "describe the top panel",
  "current_output_type": "text",
  "referenced_item": "previous panel description"
}
It should track:
active project
active topic
current task
previous task
completed steps
pending steps
current file
current file version
current application
accepted decisions
rejected approaches
unresolved questions
This component prevents the AI from suddenly answering an older topic.
