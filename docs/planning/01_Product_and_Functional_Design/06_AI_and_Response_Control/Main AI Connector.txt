MVP status: this connector uses one configured local Ollama text-generation
model through the buffered gateway contract. OpenAI, other cloud APIs,
specialized/multiple models, routing, fallback, and streaming are Deferred
Post-MVP.
The MVP connector needs:
one configured model
loopback configuration
fixed prompt rendering
timeout and cancellation
buffered complete responses
deterministic token estimation
typed error handling
