The first version should include only:
UI
Application orchestrator
Conversation state
Deterministic interpretation, confidence, and constraint extraction
Basic reference resolution
Explicit manual SQLite memory lifecycle
Deterministic keyword retrieval
Context packet builder
One buffered local Ollama connector
Rule-based validation and bounded correction
Evaluation tests

Do not initially add:
distributed services
cloud synchronization
multiple databases
autonomous memory rewriting
unrestricted background agents
complex event buses
Kubernetes
microservices
multiple simultaneous model pipelines

Also do not initially add FastAPI/local HTTP services, cloud providers, model
routing/fallback, streaming UI output, embeddings/vector stores, file indexing,
or automatic memory extraction/merge/rewrite/deletion.

The first version should remain one repository and one local application.
